# Вариант 23 — конфигурационный язык в JSON

Учебная программа читает описание конфигурации из стандартного ввода,
проверяет синтаксис, вычисляет константы и записывает результат в JSON-файл.

## Возможности

- многострочные комментарии `/+ ... +/`;
- целые положительные числа по правилу `[1-9][0-9]*`;
- строки в виде `q(текст)`;
- массивы `[значение, значение, ...]`;
- словари `{ имя -> значение. ... }`;
- константы `var имя = значение`;
- префиксные выражения `|+ имя 1|`, `|- имя 1|`, `|* имя 2|`, `|/ имя 2|`;
- функции `print(значение)` и `concat(значение, значение, ...)`;
- вложенные массивы и словари.

Синтаксический разбор выполняется библиотекой **Lark** по грамматике
LALR. JSON формируется стандартным модулем `json`.

## Требования

- Python 3.10 или новее;
- pip.

```bash
python -m venv .venv
```

Linux/macOS:

```bash
source .venv/bin/activate
```

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Установить библиотеку:

```bash
python -m pip install -r requirements.txt
```

## Запуск

Программа обязательно получает путь выходного файла через `-o` или
`--output`. Входной текст передаётся через stdin.

Linux/macOS:

```bash
python src/main.py --output result.json < examples/computer.cfg
```

Windows PowerShell:

```powershell
Get-Content -Raw examples/computer.cfg | python src/main.py -o result.json
```

При успехе JSON сохраняется в указанный файл. Диагностика ошибок
выводится в stderr, код возврата при ошибке — `1`.

## Синтаксис и примеры

### Комментарии

```text
/+ Это комментарий
   в несколько строк +/
```

### Массивы и словари

```text
[
    10,
    q(text),
    { enabled -> 1. }
]
```

```text
{
    host -> q(localhost).
    ports -> [8080, 8081].
}
```

### Константы и вычисления

```text
var workers = 4
var bonus = 2
{
    workers -> |workers|.
    total -> |+ workers bonus|.
    doubled -> |* workers 2|.
}
```

### Функции

`print(значение)` выводит текстовое представление значения в stdout и
возвращает это значение. `concat(a, b, ...)` склеивает текстовые
представления аргументов без разделителя. Обе функции можно вызывать
самостоятельно или внутри `|...|`.

Арифметические операции принимают два числа. Деление выполняется как
обычное числовое деление; деление на ноль является ошибкой.

## Функции программы и настройки командной строки

### Функции языка

- `print(значение)` выводит текстовое представление одного значения в stdout
  и возвращает исходное значение.
- `concat(a, b, ...)` объединяет текстовые представления двух или более
  значений без разделителя и возвращает строку.
- `+`, `-`, `*`, `/` выполняют арифметические операции над двумя числами.
  Деление на ноль вызывает ошибку.

### Основные функции реализации

- `convert(source)` разбирает исходный текст грамматикой Lark и запускает
  вычисление результата; при ошибке синтаксиса или вычисления сообщает
  `ConfigError`.
- `Evaluator.run(tree)` обрабатывает объявления констант по порядку и
  вычисляет итоговое значение конфигурации.
- `Evaluator.declare(node)` вычисляет значение объявления и сохраняет
  константу; повторное объявление запрещено.
- `Evaluator.evaluate(node)` вычисляет узел дерева разбора: число, строку,
  массив, словарь, ссылку, выражение или вызов функции.
- `Evaluator.evaluate_object(pairs)` собирает словарь и проверяет
  повторяющиеся ключи.
- `Evaluator.get_constant(name)` возвращает ранее объявленную константу.
- `Evaluator.calculate(operation, args)` выполняет арифметическую операцию.
- `Evaluator.print_value(node)` реализует `print()`.
- `Evaluator.concat_values(nodes)` реализует `concat()`.
- `Evaluator.to_text(value)` преобразует значение в текст для функций.
- `Evaluator.is_number(value)` проверяет, что значение является числом.
- `make_parser()` создаёт разбор аргументов командной строки.
- `main()` читает stdin, вызывает `convert()`, записывает JSON и сообщает
  об ошибках в stderr.

### Настройки запуска

- `-o FILE` или `--output FILE` — обязательный путь к выходному JSON-файлу.
- Входные данные читаются из стандартного ввода (stdin).
- JSON записывается в UTF-8 с отступом в два пробела.
- При успехе программа возвращает код `0`; при ошибке — код `1`.
- Сообщения об ошибках направляются в stderr.

## Тесты

Запустить все тесты:

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют комментарии, числа, строки, массивы, словари, вложенность,
объявление и использование констант, четыре арифметические операции,
`print()`, `concat()`, обработку ошибок и работу командной строки.

## Замечания о правилах языка

- Имена состоят только из латинских букв и `_`; цифры в именах не
  допускаются. В начале объявления `var` является ключевым словом.
  В позиции имени ключа словаря `var` допустимо.
- Число `0` и числа с ведущим нулём не соответствуют заданному правилу.
- В массиве должен быть хотя бы один элемент; словарь может быть пустым.
- Каждая запись словаря заканчивается точкой.
- Константа должна быть объявлена до использования. Повторное объявление
  константы и повторение ключа словаря считаются ошибками.
- Для `print()` используется один аргумент, для `concat()` — два или более.
  Типы аргументов `concat()` преобразуются в текст; массивы и словари
  преобразуются в компактный JSON.

запрашивает имя и email автора коммитов, задайте их командами:


не фиксировано. В настройках репозитория проверьте, что он остаётся
публичным. Ссылку на страницу репозитория отправьте в СДО.
